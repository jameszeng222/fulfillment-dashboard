口径说明
  • 筛选：时间（单选月份）与仓库 / 平台 / 后台物流商 / 国家（多选）相互叠加，作用到全部 KPI 与图表。下拉里的数字是「其他筛选条件下该选项的单量」。国家较多，下拉可直接搜索。
  • 「后台物流商」与「C 端显示物流服务商」不是一回事。后台字段是与我方签约的承运商，往往只是总包（如 WYT-USPS）；C 端字段才是客户实际看到的末端派送商（GOFO、SpeedX、OnTrac、USPS 等）。判断「客户觉得慢不慢」要看 C 端这张。
  • 单量按「履约单号」去重；件数为各 SKU 数量之和。物流运输天数 = 签收 − 签出，仅有签收的单参与。
  • 7 天达成率 = 已签收单中，物流运输天数 ≤ 7 天的占比。
  • 业务预警按 PRD 规则判定：运输超时用「仓库×物流商×目的国」历史 P90 + 2 工作日；物流未上网只认有轨迹但停在 InfoReceived/NotFound 的单，完全无轨迹的单不报（那是数据缺口，不是运输异常）。
  • 11 月是不完整月份：数据截止 —，跨月比较请切到「日均」口径。
  • 金额类字段不可用于运费看板：「当前物流预估价」98.2% 为 0，「申报金额」仅 12% 有值，故不呈现运费与费比。
